# Experiment 3: Data Preprocessing, Imputation, Distance Metrics & Feature Scaling

##  Experiment Overview
**Experiment 3** addresses essential data preprocessing techniques required for machine learning algorithms. The notebook covers replacing invalid zero values with `NaN`, performing median imputation, computing sample-to-sample distance metrics (Euclidean, Manhattan, Cosine using `scipy.spatial.distance`), and standardizing numerical features using `sklearn.preprocessing.StandardScaler`.

##  Key Findings & Results Summary

### 1. Distance Metrics Between Data Points (Sample 0 vs Sample 1)
Using `scipy.spatial.distance`:
- **Euclidean Distance**: Measures straight-line distance in feature space ($\sim 177.16$).
- **Manhattan Distance (Cityblock)**: Measures grid-based distance ($\sum |x_i - y_i| = 235.00$).
- **Cosine Distance**: Measures angular distance between feature vectors ($1 - \text{Cosine Similarity} \approx 0.0210$).

### 2. Feature Standardization (`StandardScaler`)
Features are transformed to have a mean of $0$ ($\mu = 0$) and standard deviation of $1$ ($\sigma = 1$):
$$z = \frac{x - \mu}{\sigma}$$
Standardization prevents features with larger scales (e.g., `Insulin`, `Glucose`) from dominating distance calculations.
